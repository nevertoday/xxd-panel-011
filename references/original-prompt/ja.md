# XXD Panel 011 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体のアイデンティティ、構造、姿勢、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、インディペンデント出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または環境背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**被写体、輪郭、姿勢、物語上の関係性**を抽出し、そこに含まれる最も意味のある感情の緊張、空間関係、動作の方向、または隠喩をさらに精錬して、高度に抑制されたミニマルで哲学的な線の作品として再構成します。写真を機械的になぞったり、ディテールを完全に複製したりせず、冗長なものを削除して情報を圧縮し、複雑な画面を一つの中核的な視覚命題へ凝縮します。元の被写体を識別できると同時に、元画像より静かで、より含蓄のある精神的表現を感じられるようにします。

下半分の画面は、**白または温かみのある紙白の背景、黒い連続線、大量の余白**を中心とします。線は細く、流動的で、自然であり、間、呼吸、疎密、リズムを持たせます。輪郭の省略、部分的な接続、ずれ、延長、重なり、または未完成感によって被写体を再構成できます。人物は主に姿勢と関係を、動物は動きと生命の特徴を、物体は最も重要な構造を、建築と空間は比率、境界、空間のリズムを、自然景観は地平線、流れ、輪郭、距離感を残します。元画像の内容が何であっても複雑な描写を避け、少量の線に主要な物語を担わせます。

構図は、**一つの中核的なイメージ、一組の関係、大面積の静黙な空間**を強調します。被写体は非常に小さくても、偏っていても、部分的にトリミングされても、余白の中に宙づりにされてもよく、線と線の距離、接近、分離、横断、停止、方向によって感情を形成します。余白は背景ではなく画面の重要な構成要素であり、時間、距離、孤独、親密さ、待つこと、流動、または未完の感覚を表現するために用います。画面を埋め尽くすこと、機械的な中央配置、装飾的な積み上げ、意味のない複雑な線は避けます。

全体は白黒を主体とし、**ごく少量で意味のあるアクセントカラー**だけを許可します。アクセントカラーは、上の写真の中で最も感情的価値または物語上の意味を持つ色から抽出し、一つのごく小さな物体、節点、線分、光点、または関係の焦点に置くことができます。まるで画面の中に意図して残された記憶のようにします。色は装飾ではなく、均等に分布させず、視覚的焦点に必要な最小面積を超えないようにします。

文字も同様に「精神的な精錬」を行います。場所や物体の名称を単純に書くのではなく、写真の**感情、関係、動作、時間、距離、状態、または隠喩**から、ユーザー指定の対象言語で極めて短いタイトルを生成し、少量の微小な副文、番号、または一つの抑制された哲学的な短文を添えます。文字はポスターの広告文句ではなく、アートブックの注釈のようにします。

文字は線とともに構図を形成しなければなりません。線の方向に沿って伸ばしたり、線の終端で止めたり、大きな余白の中に隠したり、被写体の輪郭と整列させたり、線に横切らせたり分断させたりできます。さらには、一本の線を自然に文字のベースライン、ガイドライン、または視覚的な接続線にすることもできます。**一つの短いタイトル + 1–2組の極小の補助文字**だけに保ち、細い字重、広い字間、小型大文字、縦組み、または非対称な位置によって、静かでハイエンドな編集感を築きます。

全体として、**静けさ、深い思索、含蓄、詩情、哲学性、瞑想性、コレクション性**を表現します。すべての線、すべての余白、すべての文字位置、すべてのアクセントカラーに意味がなければなりません。最終的な目的は写真を「線画にする」ことではなく、写真を視覚的に精錬して次元を高め、繰り返し眺めながらゆっくり理解できる、ミニマルな心象芸術作品のようにすることです。

写実的な線画、複雑な輪郭、カートゥーンイラスト、滑らかなベクターアイコン、意味のない抽象曲線、大面積の色面、商業ポスターの文字組み、装飾的な文字の積み重ね、テンプレート感は避けます。
