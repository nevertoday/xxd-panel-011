# XXD Panel 011｜哲思极简连续线条生产提示词

只处理当前任务明确提供的这一张源照片。先观察并锁定主体或不可拆分关系、轮廓、姿态、动作、结构、方向、距离与情绪；至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的主体、色彩、文案和构图。

## 精神提炼

从源图中找出最有意义的一项情绪张力、空间关系、动作方向、距离、状态或有依据的隐喻，删除冗余并把复杂画面压缩成一个核心视觉命题。结果必须能辨认原始主体与关键关系，同时比原图更沉静、更含蓄；不要机械描摹，也不要伪造人生故事或哲学含义。

人物保留姿态与关系，动物保留动作与生命特征，物件保留关键结构，建筑与空间保留比例、边界和节奏，自然景观保留地平线、走势、轮廓与距离。所有题材都只保留一个核心意象、一组关系与大面积静默空间。

## 线条与留白

使用白色或温润纸白背景与少量黑色或近黑色连续手绘线。线条纤细、流动、自然，具有停顿、呼吸、疏密、摩擦、犹豫、节奏与未完成感。只在源图事实需要时使用轮廓省略、局部连接、轻微错位、延伸、交叠、穿越、分离与开放结尾。

主体可很小、偏置、局部裁切或悬置在留白中。用线与线之间的距离、靠近、分离、穿越、停顿和方向表达时间、距离、孤独、亲密、等待、流动或未完成。留白是主动叙事，不是剩余背景。禁止填满、机械居中、复杂轮廓、无意义抽象曲线和装饰堆积。

整体以黑白为主，只允许一个极小且有意义的源图提炼点睛色。它只能落在一个物件、节点、线段、光点或关系焦点上，如同被刻意保留的记忆；不重复、不平均分布、不超过一个焦点所需面积。

## 文案与字体

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留；无文字时不生成任何伪文字。

自动文案从源图可见或有依据的情绪、关系、动作、时间、距离、状态或隐喻中提炼一个极短标题，再按需增加 1–2 组微型副文、编号或克制哲思短句。日期、地点、出处和编号等事实必须由用户提供或可靠确认，不得虚构。

文字像艺术书注释并与线条共同构图：沿线方向延伸，停在线条尽头，藏入留白，与主体轮廓对齐，被线条穿过或分隔，或让一根线自然成为文字的基线、引导线或连接。使用目标文字系统原生的细字重、宽松间距、自然的小型大写等价物、纵向排列或不对称位置；不把拉丁排版规则生硬套给其他文字。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计与壁纸不显示原照片。每张壁纸按设备独立重构，不裁切其他设备成果，不绘制系统 UI 或设备模型。连贯壁纸共同参考原照片与同一张已批准定调图，绝不串联衍生图。

硬性验收：一个核心意象、一组关系、至少三个源图线索；细而流动的黑色连续线；每次省略、连接、错位、延伸、交叠、穿越和停顿都有源图依据；纸白留白占主导并承担时间与距离；最多一个极小的有意义点睛色；文字短、准、与线条共构；无写实线稿、复杂轮廓、无意义曲线、大面积色块、商业版式、光滑矢量、3D、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
